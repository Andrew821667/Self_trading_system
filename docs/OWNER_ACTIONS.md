# Действие 1. Открыть домены в окружении (5 минут)

## Зачем

Прокси окружения режет на `403` до установления соединения три группы
хостов. Главный — **НРД**: он раскрывает обязательные предложения, выкупы и
вытеснения **по всей листингованной вселенной** и машиночитаемо. Это ровно та
популяция, которой нет в собранном инвентаре (91% его эмитентов не торгуются
на бирже).

| Хост | Что даёт |
|---|---|
| `nsddata.ru`, `nsd.ru` | корпоративные действия НРД по всем торгуемым бумагам |
| `isin.ru` | справочник ценных бумаг НРД |
| `bo.nalog.ru`, `egrul.nalog.ru` | признак П-5 чек-листа (история приобретателя) без платных агрегаторов |

## Как

1. Открыть **claude.ai/code**.
2. Нажать иконку облака — это селектор окружений. Найти окружение, в котором
   идёт эта сессия, и открыть его на редактирование.
3. Поле **Network access** уже стоит в **Custom** (иначе не работали бы
   `disclosure.ru`, `cbr.ru`, `moex.com`).
4. В поле **Allowed domains** **дописать** строки ниже к тому, что там уже
   есть. **Не заменять список** — иначе отвалятся текущие источники.

```
nsddata.ru
*.nsddata.ru
nsd.ru
*.nsd.ru
isin.ru
*.isin.ru
bo.nalog.ru
egrul.nalog.ru
```

5. Галочка **«Also include default list of common package managers»** должна
   остаться как есть.
6. Сохранить.

## Важные оговорки

- Одна строка — один домен. Ведущая `*.` покрывает все поддомены.
- Изменения подхватывает **новая сессия**; уже запущенная работает со старыми
  правилами. После сохранения напиши мне — если прокси всё ещё отдаёт `403`,
  значит сессию надо перезапустить.
- Если захочешь, чтобы я делал страницы-панели (artifacts) со статусом, в этот
  же список нужна строка `*.frame.claudeusercontent.com` — без неё я не смогу
  читать собственные опубликованные страницы.

# Действие 2. Собрать раскрытие по адресному списку эмитентов

## Что выяснилось на живом сайте (2026-08-25)

Автоматизированный сбор с `e-disclosure.ru` **невозможен, и это проверено, а
не предположено.** Два прогона на машине владельца:

1. Playwright-браузер сам заполняет форму → сайт отвечает капчей: «Ваше
   поведение похоже на поведение автоматизированных систем», головоломка на
   поворот картинки.
2. Тот же браузер, но ведёт человек → `ERR_EMPTY_RESPONSE`, сервер рвёт
   соединение вообще.

Дело не в том, кто нажимает: браузер под управлением Playwright распознаётся
как автоматика независимо от этого. Решать капчу и маскировать браузер здесь
никто не будет — это обход защиты, поставленной владельцем чужого сайта.

Поэтому сбор идёт **в обычном браузере владельца, вручную**, а машинная часть
— только разбор уже сохранённых файлов.

## Сработавший способ (2026-09-05): один поиск вместо 74 компаний

Адресный список эмитентов не понадобился. На сайте есть **«Поиск по
сообщениям»**, который выдаёт сразу все сообщения нужных типов по **всем
агентствам**, а не только по Интерфаксу. Собрано за вечер: **533 сообщения
за 2019–2025** от 321 эмитента.

Как это делается:

1. Вкладка **«Поиск по сообщениям»**.
2. В фильтре типов отметить четыре: добровольное предложение, обязательное
   предложение, уведомление о праве требовать выкупа, требование о выкупе.
3. Даты — **по одному году** (`01.01.2019` – `31.12.2019`).
4. Внизу слева **«Отображать записей»** поставить на максимум — тогда весь
   год умещается на одной странице.
5. `Cmd+S` → формат **«Веб-архив»** (не «исходный код страницы» — таблица
   результатов рисуется скриптом, и в исходном коде её нет).
6. Повторить для 2020…2025.

Разбор — `scripts/parse_saved_interfax.py`, читает `.webarchive` напрямую.

## Осторожно с именами файлов

Safari называет каждое сохранение одинаково. Пока файлы лежат в Загрузках,
второе получает суффикс `2`, третье `3` и так далее — но **после переноса в
проект Загрузки пустеют, и следующее сохранение снова получает имя без
суффикса**, а `mv` перезаписывает им уже перенесённый файл.

Так был потерян веб-архив за 2019 год (сами данные восстановлены из истории
git, исходный файл — нет). Переименовывай сразу при сохранении —
`2019.webarchive`, `2020.webarchive` — или переноси после каждого
сохранения, а не все разом в конце.
