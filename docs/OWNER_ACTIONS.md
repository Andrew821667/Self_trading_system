# Действие 1. Открыть домены в окружении (5 минут)

## Зачем

Прокси окружения режет на `403` до установления соединения три группы
хостов. Главный — **НРД**: он раскрывает обязательные предложения, выкупы и
вытеснения **по всей листингованной вселенной** и машиночитаемо. Это ровно та
популяция, которой нет в собранном инвентаре (91% его эмитентов не торгуются
на бирже).

| Хост | Что даёт |
|---|---|
| `nsddata.ru`, `nsd.ru` | корпоративные действия НРД по всем торгуемым бумагам |
| `isin.ru` | справочник ценных бумаг НРД |
| `bo.nalog.ru`, `egrul.nalog.ru` | признак П-5 чек-листа (история приобретателя) без платных агрегаторов |

## Как

1. Открыть **claude.ai/code**.
2. Нажать иконку облака — это селектор окружений. Найти окружение, в котором
   идёт эта сессия, и открыть его на редактирование.
3. Поле **Network access** уже стоит в **Custom** (иначе не работали бы
   `disclosure.ru`, `cbr.ru`, `moex.com`).
4. В поле **Allowed domains** **дописать** строки ниже к тому, что там уже
   есть. **Не заменять список** — иначе отвалятся текущие источники.

```
nsddata.ru
*.nsddata.ru
nsd.ru
*.nsd.ru
isin.ru
*.isin.ru
bo.nalog.ru
egrul.nalog.ru
```

5. Галочка **«Also include default list of common package managers»** должна
   остаться как есть.
6. Сохранить.

## Важные оговорки

- Одна строка — один домен. Ведущая `*.` покрывает все поддомены.
- Изменения подхватывает **новая сессия**; уже запущенная работает со старыми
  правилами. После сохранения напиши мне — если прокси всё ещё отдаёт `403`,
  значит сессию надо перезапустить.
- Если захочешь, чтобы я делал страницы-панели (artifacts) со статусом, в этот
  же список нужна строка `*.frame.claudeusercontent.com` — без неё я не смогу
  читать собственные опубликованные страницы.

# Действие 2. Собрать архив Интерфакса на своей машине

НРД оказался платным, так что это теперь **основной путь**, а не запасной.
`e-disclosure.ru` обслуживает ~90%
листингованных эмитентов, но моей песочнице отдаёт JS-заглушку антибота вместо
данных. Обходить её я не стал: она поставлена владельцем сайта, и обходить
её — не то, что делают гости. Обычный браузер проходит проверку штатно, потому
что она на человека с браузером и рассчитана.

## Что именно нужно

Сообщения четырёх типов за 2019–2025. Коды — единая нумерация Банка России,
подтверждены в живой форме поиска:

| Код | Название в форме |
|---|---|
| 181 | Поступление эмитенту добровольного предложения о приобретении его эмиссионных ценных бумаг |
| 182 | Поступление эмитенту обязательного предложения о приобретении его эмиссионных ценных бумаг |
| 184 | Поступление эмитенту уведомления о праве требовать выкупа эмиссионных ценных бумаг эмитента |
| 185 | Поступление эмитенту требования о выкупе эмиссионных ценных бумаг эмитента |

## Запуск — один блок, работает на любой машине

Клонирует, если проекта ещё нет; обновляет, если есть. Копировать целиком:

```sh
cd ~ && [ -d Self_trading_system ] || git clone -b claude/new-project-spec-wx4utz https://github.com/Andrew821667/Self_trading_system.git
cd ~/Self_trading_system && git pull
[ -d .venv ] || python3 -m venv .venv
source .venv/bin/activate
python scripts/owner/collect_interfax.py
```

Две вещи, на которых легко споткнуться, и обе — про macOS:

- **`python3`, а не `python`.** Голого `python` в macOS нет; он появляется
  только внутри активированного venv — поэтому в последней строке уже
  `python`, а в третьей ещё `python3`.
- **venv обязателен.** Системный Python на свежих macOS запрещает
  `pip install` в себя (`externally-managed-environment`), и установка
  playwright упала бы.

В новом окне терминала venv надо активировать заново:

```sh
cd ~/Self_trading_system && source .venv/bin/activate && python scripts/owner/collect_interfax.py
```

## Как это работает: ведёшь ты, скрипт записывает

**Проверено на живом сайте 2026-08-25 и переделано.** Первая версия сама
заполняла форму — это тупик: сайт распознаёт автоматизированный браузер и
отвечает капчей («Ваше поведение похоже на поведение автоматизированных
систем», головоломка на поворот картинки). Правкой селекторов это не лечится,
и решать капчу программно скрипт не будет.

Поэтому роли разделены: **проверку проходит человек, скрипт только снимает то,
что уже открыто на экране.** Запросов к сайту он не делает вообще — весь
трафик порождают твои клики.

```sh
python scripts/owner/collect_interfax.py
```

Откроется окно браузера. Дальше:

1. Пройди проверку «вы не бот», если она появилась.
2. Отметь четыре типа сообщений (список выше — 181, 182, 184, 185).
3. Поставь даты за **один год** (01.01.2019 – 31.12.2019) и нажми поиск.
4. Листай страницы выдачи. Каждую скрипт записывает сам, в терминале видно
   счётчик.
5. Год кончился — поменяй даты на следующий. И так до 2025.

Закончил — Ctrl+C в терминале или просто закрой окно браузера.

Профиль браузера сохраняется в `.interfax-profile/`, так что пройденную
проверку не придётся повторять при каждом запуске. Порядок годов и число
запусков значения не имеют: сообщения копятся в один файл и не дублируются.

Сразу закоммитить и запушить результат мне:

```sh
python scripts/owner/collect_interfax.py --push
```
