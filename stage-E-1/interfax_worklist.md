# Адресный список эмитентов для e-disclosure.ru

**74 компаний.** Это не «весь рынок за семь лет», а именно те
эмитенты, по которым в собранном материале есть дыра: торгуемые бумаги, чьё
раскрытие идёт через Интерфакс и потому недоступно в облачной сессии.

Откуда список:

- **событие E-1** — событие семейства уже найдено в AZIPI, бумага торгуется
  (`inventory/tradability.csv`);
- **делистинг** — бумага перестала торговаться, а делистинг есть прямое
  основание права требовать выкупа по ст. 75 (`inventory/delisting_triggers.csv`).
  Здесь же 2019–2020, куда архив AZIPI не достаёт вовсе.

## Что делать с каждой строкой

В своём обычном браузере на `e-disclosure.ru` найти компанию по названию или
ИНН, открыть её ленту раскрытия и сохранить страницы, где встречаются
сообщения четырёх типов (`Cmd+S` → «Веб-страница, только HTML») в папку
`stage-E-1/documents/interfax/pages/`:

    181  Поступление эмитенту добровольного предложения…
    182  Поступление эмитенту обязательного предложения…
    184  Поступление эмитенту уведомления о праве требовать выкупа…
    185  Поступление эмитенту требования о выкупе…

Ничего не нашлось у эмитента — просто пропустить, отрицательный результат
тоже результат. Порядок не важен, останавливаться можно в любой момент.

Разбор сохранённого:

```sh
uv run python scripts/parse_saved_interfax.py \
    --pages stage-E-1/documents/interfax/pages \
    --out stage-E-1/documents/interfax/messages.jsonl
```
