# Список событий, ожидающих текста документа с e-disclosure.ru

Назначение: список конкретных событий (эмитент, ISIN, тип, дата), для
которых нужен текст первичного документа с e-disclosure.ru (цена
процедуры, ценовая база, банк-гарант, приобретатель), собранный отдельной
сессией/устройством с рабочим доступом к сайту. Цель — чтобы вторая
сессия искала конкретные страницы по эмитенту и дате, а не перебирала
архив подряд.

**Сейчас список пуст.** Ни один источник, доступный этой сессии
(disclosure.skrin.ru, cbr.ru, web.archive.org), не отдал реальную выдачу
результатов поиска по нужным типам сообщений — см.
`coverage_report.md`, раздел "Обновление 2026-08-23 (сессия 2)". Строки
появляются здесь только вместе с соответствующей записью в
`inventory/events.jsonl` (см. протокол в `README.md`) — никогда раньше.

## Формат строки (заполняется по мере появления реальных событий)

```text
- event_id: <как в inventory/events.jsonl>
  issuer: <точное наименование эмитента>
  isin: <ISIN>
  event_type: <voluntary_or_mandatory_offer | squeeze_out_request_95 | forced_buyback | buyback_art_75_76>
  announcement_date: <YYYY-MM-DD — дата события для отсечки при поиске>
  что нужно: <price | price_basis | guarantor_bank | acquirer | полный текст>
  наводка: <откуда взят факт существования события — ссылка/источник>
```

## Инструкция для второй сессии (человек с браузером)

1. Открыть `https://www.e-disclosure.ru/poisk-po-soobshheniyam`.
2. В фильтре типа сообщения отметить (коды подтверждены на боевом сайте
   22.08.2026, см. `coverage_report.md`):
   - 181 — Поступление эмитенту добровольного предложения о приобретении
     его эмиссионных ценных бумаг
   - 182 — Поступление эмитенту обязательного предложения о приобретении
     его эмиссионных ценных бумаг
   - 184 — Поступление эмитенту уведомления о праве требовать выкупа
     эмиссионных ценных бумаг эмитента
   - 185 — Поступление эмитенту требования о выкупе эмиссионных ценных
     бумаг эмитента
   - опционально 245/246 — изменения, внесённые в уже поступившие
     добровольное/обязательное предложение (правки, TZ 6.6)
3. Диапазон дат — по годам, 2019–2025 (за один запрос форма ограничивает
   период, потребуется несколько проходов).
4. Для `buyback_art_75_76` (выкуп по ст. 75–76) выделенной категории в
   таксономии не нашлось — см. `coverage_report.md`, кандидаты
   "Приобретение эмитентом собственных голосующих акций" и "Принятие
   решения о приобретении размещённых эмитентом акций"; требует
   отдельной проверки по текстам.
5. Каждое найденное сообщение — сохранить как есть (см.
   `README.md`: `documents/<event_id>/<doc_id>.<ext>` +
   `.meta.json` с `url`, `published_at`, `retrieved_at`, `sha256`), затем
   строку в `inventory/events.jsonl`.
6. По готовности — обновить этот файл (убрать закрытые строки, добавить
   новые пробелы, если что-то не нашлось) и `coverage_report.md`.
