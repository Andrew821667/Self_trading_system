# scripts/browser/

Скрипты, которым разрешено поднимать настоящий Chromium (Playwright).
Каталог существует отдельно, потому что на него выдано разрешение в
`.claude/settings.json`:

```json
"Bash(uv run python scripts/browser/*)"
```

Правило узкое намеренно: разрешён не «любой python», а только запуск файлов
из этого каталога — так видно, что именно получило доступ к браузеру.

## Запуск браузера в этой среде

Chromium предустановлен, но версия сборки не совпадает с той, которую ищет
установленный пакет `playwright`, поэтому путь к бинарю указывается явно:

```python
BROWSER = "/opt/pw-browsers/chromium-1194/chrome-linux/chrome"
p.chromium.launch(executable_path=BROWSER, args=[f"--proxy-server={proxy}", ...])
```

Весь исходящий трафик идёт через прокси окружения (`HTTPS_PROXY`), и домен
должен быть в его allowlist — иначе соединение рвётся до сайта.

## Граница, которую эти скрипты не переходят

Настоящий браузер выполняет JS сайта так, как сайт и задумал: проверки,
рассчитанные на браузер, проходят штатно. Это **не** обход защиты.

Обходом было бы разобрать антибот-челлендж и подделать токен — этого здесь
нет и быть не должно.

И то и другое одинаково требует вежливости к чужой инфраструктуре: паузы
между запросами, никакого параллелизма по одному хосту, остановка при
устойчивых отказах.
