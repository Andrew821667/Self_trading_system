# refdata

Scope (TZ section 26 `refdata` schema, TZ 6.4/E1): instrument master —
issuers, instruments, issuer-instrument mapping (listings, share classes,
changes from corporate actions). Resolves a structured event to concrete
instruments; unresolved/ambiguous resolution must surface as `AMBIGUOUS`,
never a best guess.

Status: **not started** — part of Stage E1, gated per `ROADMAP.md`.
