# reporting

Scope (TZ section 21): daily equity/positions/risk/incidents report, weekly
strategy health + benchmark + drift report, annual economic report (net of
trading costs, tax, fixed costs, vs. benchmark, continuation verdict).

LLM use is allowed here (TZ 4.2 lists `reporting-service` as one of the
three services permitted to call an LLM) but only for narrative framing —
the underlying numbers come from the journal/database, never from a model.

Status: **not started**, gated per `ROADMAP.md`.
